Which tool should the agent call? We asked a model that cannot write text.

Jev (TypeSafe) picks from a menu with probabilities instead of generating an answer. We gave it 1,000 user requests and a catalogue of 36 skills and agents, and ran every current Claude model on the same requests.

Jev → 94% correct pick, 0.5 s, 17 cents per 1,000.

Claude Haiku 4.5, thinking off → 89%, 2.4 s, $2.65 per 1,000.

Claude Sonnet 5, thinking off → 95%, 2.6 s, $4.80 per 1,000.

Claude Fable 5.1 → 98%, 3.0 s.

So on routing, Jev beats the cheapest Claude, sits in the Sonnet band, and trails the top models by a few points, at five times the speed of any of them.

The video shows the router picking, one request after another, then a thousand, then the ranking.

Measured, not quoted: our own run, Claude via Claude Code at low effort with thinking off, Jev via OpenRouter, 200-case preliminary cut of a 1,000-case set, 95% intervals in the report. Full run and code on GitHub, link in comments.
