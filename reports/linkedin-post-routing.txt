Which tool should the agent call? We asked a model that cannot write text, and it beat the cheapest Claude.

Jev (TypeSafe) picks from a menu with probabilities instead of generating an answer.

We gave it real user requests and a catalogue of 36 skills and agents, then ran every current Claude model on the same requests.

Jev → 94% correct pick, 0.5 s, 17 cents per 1,000.

Claude Haiku 4.5 → 89%, 2.4 s, $2.66 per 1,000.

Claude Sonnet 5 → 95%, 2.6 s, $4.82 per 1,000.

Claude Fable 5.1 → 97%, 3.0 s, $19.51 per 1,000.

So Jev picks the right tool as well as Haiku, five times faster, and lands within a point of Sonnet 5 at a thirtieth of the cost.

All Claude numbers are with thinking off, which is the fastest and cheapest shape for a router. Turning thinking on buys Haiku five points and costs it five seconds.

The video shows the router picking, one request after another, then a thousand, then the ranking.

Measured, not quoted. Our own run, Claude via Claude Code at low effort, Jev via OpenRouter. Preliminary cut, same cases for every model. Datasets, harness and results are public, link in comments.
